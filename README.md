# PhongTroXanhMobileApp

Ứng dụng Flutter Phòng Trọ Xanh. Source và tài liệu nằm trong [`mobile`](mobile).

- [`mobile/mobile-mock`](mobile/mobile-mock): bản demo hiện tại.
- [`mobile/mobile`](mobile/mobile): bản dành cho phát triển và tích hợp backend.
- [`mobile/docs`](mobile/docs): thiết kế, luồng nghiệm thu và handoff API.

Xem hướng dẫn chạy của từng app. Hiện chưa có backend được tích hợp.
